LiveManager 1.4

Logic Pro projects now sit alongside your Ableton sets.

New

  • Logic Pro support. Point LiveManager at a folder containing Logic projects and they appear as songs, with tempo, time signature, track count and the version of Logic that saved them — rated, tagged and filed into albums just like Ableton sets.
  • Alternatives become versions. Each of a Logic project's alternatives is listed under Versions, newest first, so you can see when each was last saved.
  • Bounces are found automatically. Logic keeps bounces and recorded takes in the same folders, so LiveManager ranks them: audio named after the project, or sitting in a Bounces folder, is offered first — a stray loop or take won't hijack the demo slot.
  • Volume slider in the player bar, remembered between launches.

Fixed

  • A repeated project file could crash the app on launch, with no way back in. LiveManager now repairs the duplicate instead of stopping.
  • "Open in Ableton" now says Logic when the song is a Logic project, and opens the project rather than a file inside it.
